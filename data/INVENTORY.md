# Legacy file inventory

State of the pre-restructure files after the Phase 0/3 reorg. Nothing was
deleted; everything below is gitignored.

## Root (kept)

`README.md`, `pyproject.toml`, `environment.yml`, `.gitignore`,
`.gitattributes`, `LICENSE` — repo scaffolding.
`model.txt`, `nguasach.xlsx`, `cc.en.300.vec` — inputs the pipeline reads
(also mirrored, where small, into `data/raw/`). Gitignored; see
`data/README.md` for checksums.
